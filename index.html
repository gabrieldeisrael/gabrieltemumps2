Estrutura do Pacote

pcsx2-portable/
├── pcsx2.AppImage ← emulador (71 MB)
├── launch.sh ← script de lançamento
├── bios/ ← coloque sua BIOS aqui
├── memcards/ ← saves dos memory cards
├── roms/ ← seus jogos (.iso, .bin…)
├── snaps/ ← screenshots
└── sstates/ ← save states

Como Usar

01
Extraia o pacote
Extraia em qualquer lugar — HD externo, pendrive, pasta local.

Windows Clique com botão direito no .zip → Extrair Tudo
Linux unzip pcsx2-portable-linuxmint.zip
02
Adicione a BIOS do PS2
Copie o arquivo de BIOS do seu PlayStation 2 para a pasta bios/.
⚠️
Use sua própria BIOS. Este site é contra a pirataria de jogos e BIOS. Extraia a BIOS do seu console original — nunca faça download de fontes não oficiais.
03
Execute o script
Windows Este emulador é exclusivo para Linux — use o instalador oficial para Windows.

Linux Mint Dê permissão e execute:
chmod +x launch.sh && ./launch.sh
04
Tudo portátil ✓
O BIOS e os memory cards ficam dentro da própria pasta. Leve para onde quiser.
